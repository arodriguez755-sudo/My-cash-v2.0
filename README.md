# Mis Finanzas (app instalable en Android)

## Publicar gratis en GitHub Pages
1. Entra a github.com → **New repository** (nombre: `finanzas`, público).
2. **Add file → Upload files** y sube TODO el contenido de esta carpeta (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png).
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
4. Espera 1–2 minutos. Tu app quedará en `https://TU-USUARIO.github.io/finanzas/`.

## Instalar en el celular
Abre esa dirección en Chrome (Android) → menú ⋮ → **Instalar app** / **Agregar a pantalla de inicio**.

## Notas
- Los datos se guardan solo en el celular. Usa **Descargar** (en Resumen) para hacer respaldos.
- Los avisos de la app salen cuando la abres. Para recordatorios con la app cerrada, usa **Exportar a mi calendario** en la pestaña Pagos.
